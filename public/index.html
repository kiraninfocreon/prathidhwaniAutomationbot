LinkedIn

Posts the daily job update to a LinkedIn Company Page (or your profile) using LinkedIn's official API — no browser automation, nothing that risks the account. LinkedIn has no supported way for third-party apps to post into LinkedIn Groups any more, so a Page/profile post is the zero-cost option that works.

App credentials —

Create a free app at developer.linkedin.com, add the "Share on LinkedIn" product (instant) and, if you want to post as your Company Page, also request the free "Community Management API" product (needs a short review — still $0). Then paste the Client ID/Secret below and set the Redirect URI on the app to exactly match the one shown here.

Facebook

Posts the daily job update to a Facebook Page you manage using the official Graph API. Meta withdrew Groups-posting access from third-party apps years ago, so auto-posting into Facebook Groups isn't possible without an unofficial, account-risking workaround — a Page post is the supported, zero-cost equivalent.

App credentials —

Create a free app at developers.facebook.com (type: Business), add Facebook Login, and set this exact Redirect URI on it. Paste the App ID/Secret below.
